Theory: Online Algorithms

Consegna: Dimostrare nel modo più semplice possibile la ricorrenza di Welford per la varianza, indicando chiaramente quali proprietà della media sono state usate e che tipo di manipolazioni algebriche.

1. Definizioni Iniziali

Definiamo Mn come la media dei primi n campioni e Sn come la somma dei quadrati delle deviazioni dalla media:

Sn = ∑(i=1 → n) (xi - Mn)2

2. Scomposizione ed Espansione

Manipolazione algebrica: Partiamo dalla scomposizione di Sn isolando l'ultimo termine xn:

Sn = ∑(i=1 → n-1) (xi - Mn)2 + (xn - Mn)2

Sfruttiamo la relazione nota tra la media corrente e la precedente (Mn = Mn-1 + (xn - Mn-1) / n). Sostituendo Mn all'interno della sommatoria ed espandendo il quadrato del binomio, otteniamo tre termini distinti:

∑ (xi - Mn-1)2    -    2(Mn - Mn-1)∑(xi - Mn-1)    +    ∑ (Mn - Mn-1)2

3. Applicazione delle Proprietà della Media

Analizzando i tre termini appena ottenuti, applichiamo le proprietà fondamentali:

  • Il primo termine è per definizione esattamente Sn-1.
  • Il secondo termine si annulla (diventa 0). Qui interviene la proprietà fondamentale della media: la somma degli scarti di un insieme di valori dalla loro media è sempre rigorosamente zero, ovvero ∑(xi - Mn-1) = 0.
  • Il terzo termine, essendo una costante che viene sommata n-1 volte, si semplifica in: (n-1)(Mn - Mn-1)2.

L'equazione si è quindi ridotta a:

Sn = Sn-1 + (n-1)(Mn - Mn-1)2 + (xn - Mn)2

4. Sostituzione Finale

Manipolazione algebrica finale: Sapendo che xn - Mn = (xn - Mn-1) * (n-1)/n, sostituiamo questi valori nell'equazione precedente e raccogliamo a fattore comune. Risolvendo le frazioni all'interno delle parentesi, si arriva in modo pulito alla formula finale iterativa:

Sn = Sn-1 + (xn - Mn-1)(xn - Mn)

// Funzione 1: Modifica il contenuto HTML
function cambiaTesto() {
  const mioDiv = document.getElementById("target-div");
  mioDiv.innerHTML = "<strong>Magia! ✨</strong> Il contenuto è modificato.";
}

// Funzione 2: Modifica lo stile CSS
function cambiaStile() {
  const mioDiv = document.getElementById("target-div");
  mioDiv.style.backgroundColor = "#0284c7"; 
  mioDiv.style.color = "#ffffff"; 
  mioDiv.style.border = "3px dashed #38bdf8"; 
  mioDiv.style.borderRadius = "20px"; 
  mioDiv.style.transform = "scale(1.02)"; 
}

// Funzione 3: Nasconde o mostra
function nascondiMostra() {
  const mioDiv = document.getElementById("target-div");
  if (mioDiv.style.display === "none") {
    mioDiv.style.display = "block"; 
  } else {
    mioDiv.style.display = "none"; 
  }
}

// Funzione 4: Reset
function resetDiv() {
  const mioDiv = document.getElementById("target-div");
  mioDiv.innerHTML = "Questo è il testo originale del DIV. Usa i bottoni qui sotto per modificarmi!";
  mioDiv.style.backgroundColor = "";
  mioDiv.style.color = "";
  mioDiv.style.border = "";
  mioDiv.style.borderRadius = "";
  mioDiv.style.transform = "";
  mioDiv.style.display = "block";
}

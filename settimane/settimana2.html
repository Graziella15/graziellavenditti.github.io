Teoria

Formula naive:

Var(X) = E[X²] - (E[X])²

Ricorrenza di Welford:

n = n + 1
δ = x - media
media = media + δ / n
δ2 = x - media
M2 = M2 + δ · δ2

varianza popolazione = M2 / n
varianza campionaria = M2 / (n - 1)

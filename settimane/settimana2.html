📚 Teoria: Generare distribuzioni partendo dall'Uniforme

I computer generano numeri pseudo-casuali con distribuzione Uniforme tra 0 e 1.

🟢 Distribuzioni Continue

  • Esponenziale: X = -ln(U) / λ
  • Normale / Gaussiana: Z = √(-2 ln(U1)) × cos(2π U2)
  • Cauchy: X = x0 + γ tan(π(U - 0.5))

🔵 Distribuzioni Discrete

  • Bernoulli: Se U < p → 1 (Successo), altrimenti 0.
  • Binomiale: Somma dei successi in n test di Bernoulli indipendenti.

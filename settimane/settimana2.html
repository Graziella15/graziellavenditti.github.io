📚 Teoria: Generare distribuzioni partendo dall'Uniforme

I computer generano numeri pseudo-casuali con distribuzione Uniforme tra 0 e 1. Per ottenere altre distribuzioni, si applicano specifiche trasformazioni matematiche a questi valori di base (spesso indicati con la lettera U).

🟢 Distribuzioni Continue

  • Esponenziale (Trasformata Inversa)
    Formula: X = -ln(U) / λ
  • Normale / Gaussiana (Box-Muller)
    Formula: Z = √(-2 ln(U1)) × cos(2π U2)
  • Cauchy (Trasformata Inversa)
    Formula: X = x0 + γ tan(π(U - 0.5))
  • Chi-Quadro (χ2) (Composizione)
    Concetto: Somma dei quadrati di k variabili Normali standard.
  • T di Student (Rapporto)
    Concetto: Rapporto tra una Normale standard e la radice di una Chi-Quadro.
  • Weibull (Trasformata Inversa)
    Formula: X = λ (-ln(U))1/k

🔵 Distribuzioni Discrete

  • Bernoulli (Soglia Diretta)
    Formula: Se U < p → 1 (Successo), altrimenti 0.
  • Binomiale (Somma di Bernoulli)
    Concetto: Somma di successi in n prove indipendenti.
  • Geometrica (Trasformata Inversa Discretizzata)
    Formula: X = ⌊ ln(U) / ln(1-p) ⌋
  • Poisson (Moltiplicazione Sequenziale)
    Concetto: Moltiplicare U1 × U2... finché il prodotto < e-λ.
  • Uniforme Discreta (Scalatura e Arrotondamento)
    Formula: X = a + ⌊ U × (b - a + 1) ⌋

Teoria essenziale

Formula naive della varianza:

Var(X) = E[X²] - (E[X])²

Ricorrenza di Welford:

n = n + 1
δ = x - media
media = media + δ / n
δ2 = x - media
M2 = M2 + δ · δ2

Alla fine:

varianza popolazione = M2 / n
varianza campionaria = M2 / (n - 1)

L'algoritmo di Welford è più stabile numericamente della formula naive, soprattutto quando i numeri sono molto grandi e molto vicini tra loro.
